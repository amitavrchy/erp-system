# ERP System client

Next.js App Router application for the ERP System. Overview, environment variables, and setup for both apps are in the [repository README](../README.md).

## Scripts

```bash
npm install
npm run dev
npm run build
npm run start
npm run lint
```

`dev` and `start` read `PORT` when it is set. `build` typechecks the app and writes the production output. `lint` runs ESLint.
